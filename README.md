# AI Document Assistant

## Project Overview
A Python-based application that reads PDF documents and extracts their text. The goal is to develop it into an AI-powered assistant that answers questions using uploaded documents.

## Current Features
- Create PDF documents using Python.
- Open and read PDF files.
- Extract text from PDF pages.
- Display extracted document content.

## Technologies Used
- Python
- PyMuPDF
- Git and GitHub
- Visual Studio Code

## Project Status
Foundation stage – under development.

## Planned Features
- Upload multiple PDF documents.
- Search document content.
- Ask questions about documents using AI.
- Generate answers with page references.
- Build a web-based chat interface.
